## 10. Key Decisions & Lessons Learned

1. **CI strictness matters:** Both `clippy` (with `-D warnings`) and ESLint (`no-explicit-any`) enforce zero-tolerance policies in the CI pipelines. All code must pass these before merge.

2. **Cross-platform compilation:** The Rust backend targets both Windows (development) and Linux (CI). OS-specific imports like `std::ptr` for DPAPI must be gated with `#[cfg(target_os = "windows")]`.

3. **Monaco vs. CodeMirror:** The "absolute pinnacle" decision was to use Monaco Editor with `monaco-vscode-api` polyfill rather than CodeMirror 6. While CodeMirror is lighter, Monaco provides the authentic VS Code extension compatibility layer needed for this project's ambition.

4. **Type safety enforcement:** React 19 with strict TypeScript catches `any` types that ESLint also rejects. The pattern `catch (e: unknown) { const msg = e instanceof Error ? e.message : String(e); }` is the canonical fix.

5. **PR merge timing:** PR #38 was merged before CI fixes landed, requiring PR #39 to bring `main` green. Future workflow: always wait for green CI before merging.

## 12. Evening Session: Multimodal base64 & Context Caching Pipeline (Issue #36)

### Status: ✅ CLOSED

### Design Decision — Zero-Compromise Multimodal & Fallback Pipeline
The user requested the absolute pinnacle design for Issue #36. The implemented architecture achieves this via:

| Feature | Design Implementation | Rationale |
|---------|-----------------------|-----------|
| **Zero-Copy Path Transfer** | Frontend passes absolute system path; Rust reads directly from disk. | Bypasses Tauri WebView IPC serialization bottleneck (prevents freezing the UI). |
| **Google Files API Caching** | Files > 2MB uploaded via Files API; referenced by remote URI in subsequent turns. | Optimizes context window and saves API token usage/latency. |
| **Pure-Rust PDF Extraction Fallback** | PDF parsing using the pure-Rust `pdf-extract` crate inside the Rust backend. | Automatically extracts layout-preserved text from PDF attachments and appends inline to prompt for local VLMs (which only support images natively). Works on Windows without external system binaries. |
| **Drag-and-Drop & Dialogs** | Window-wide drop listener + FFI command calling the native OS picker (`rfd`). | Provides high-fidelity UX where users can drag/drop files or click the paperclip attachment icon. |
