### Updated Issues (Partially Completed)

#### **Issue #44** — `[TASK] Implement Zero-Copy Vector Column Mapping`
- **What is completed:** Float-to-byte zero-copy slice casting implemented in `db.rs` via raw pointers (`std::slice::from_raw_parts`), successfully inserting binary BLOBs into sqlite-vec `vec0` tables.
- **What is missing:** The `zerocopy` crate (declared in `Cargo.toml`) is not imported. We need to replace `unsafe` raw pointers with the `zerocopy::AsBytes` (or newer `zerocopy` API) trait for safe, guaranteed zero-copy column mapping.

#### **Issue #48** — `[TASK] Create Isolated Process Execution Sandbox`
- **What is completed:** Spawns compilation commands via `tokio::process::Command` in `main.rs` (`run_process_and_stream`), successfully piping standard streams and detecting exit codes.
- **What is missing:** Lacks process timeouts, memory limits, CPU core allocations/resource constraints, or true OS-level sandboxing (e.g., Windows Job Objects, Linux cgroups).

#### **Issue #49** — `[TASK] Implement AST-Targeted Patch Generator`
- **What is completed:** Self-healing compiler loop in `main.rs` extracts the failing file name from stderr, dispatches a request to Gemini for a fix, extracts the code block, and overwrites the file.
- **What is missing:** Line-number/column-number error parsing is not implemented. The engine reads/sends the *entire* file to the LLM rather than using Tree-sitter to isolate the specific failing AST scope (e.g., function/struct), and replaces the entire file rather than applying targeted AST patching.

#### **Issue #23** — `[TASK] Integrate structured tracing-subscriber logging`
- **What is completed:** Централизованный custom in-memory log buffer (`AppState.logs`) tracks logs across all backend modules, with a `get_logs` Tauri IPC command exposing them to the frontend. Keyring credentials are masked/encrypted.
- **What is missing:** The `tracing` or `tracing-subscriber` crates are not in `Cargo.toml`. Lacks log level filters (debug/info/warn/error), file rotation, ANSI-colored console logs, or structured JSON telemetry streams.
