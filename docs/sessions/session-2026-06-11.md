## 2. Codebase Walkthrough & Component Architecture

### A. Rust Backend (`src/backend/src/`)

1. **[main.rs](file:///d:/Project/Antigravity/src/backend/src/main.rs)**:
   - Contains the core application state (`AppState`), Tauri v2 command invoke routers, and configuration initialization.
   - Implements the sandboxed process runner (`run_process_and_stream`) that executes compilers/checkers under Windows Job Objects limits (512MB RAM, 32 processes), sets low priority, enforces a 30s timeout, and caps total stdout/stderr outputs to 5MB.
   - Coordinates the **AST-Targeted Self-Healing loop**:
     - Automatically creates a sandbox branch (`antigravity-healing-temp`).
     - Executes compilation/testing tasks.
     - On failure, parses file coordinates (line/col) from stderr logs (supporting general drive formats and TS parenthesized coordinates).
     - Resolves quick-fixes from the LSP client. If none are found, uses Tree-sitter to isolate the structural AST scope enclosing the error.
     - Extract referenced symbols and looks up definition contexts from the SQLite database to build a RAG context.
     - Queries Gemini/Local LLM for a structured JSON patch, validates syntax with Tree-sitter, inserts imports safely, and writes changes.
     - Retries up to 3 times; on success, commits changes to the target branch, deletes the temp branch, and returns. On failure, rolls back changes.

2. **[parser.rs](file:///d:/Project/Antigravity/src/backend/src/parser.rs)**:
   - Integrates the `tree-sitter` library to parse Rust, TypeScript, and TSX files.
   - Extracts structural AST symbol coordinates (functions, structs, impls, classes, interfaces) and signatures.
   - Implements `isolate_ast_scope` to crawl the AST tree from a specific coordinate up to its enclosing structural block (e.g., `function_item`, `class_declaration`).

3. **[watcher.rs](file:///d:/Project/Antigravity/src/backend/src/watcher.rs)**:
   - Operates a real-time filesystem watcher using the `notify` crate, ignoring folders like `.git`, `node_modules`, `target`, and `dist`.
   - Debounces changes for 500ms to avoid runaway re-indexing.
   - Triggers background indexing: updates AST symbol cache, runs SQLite upserts, requests embeddings from Gemini/OpenAI endpoints, saves results to `vec_symbols`, and refreshes the in-memory SIMD search cache.

4. **[db.rs](file:///d:/Project/Antigravity/src/backend/src/db.rs)**:
   - Configures the SQLite database and registers the `sqlite-vec` extension globally using `rusqlite::ffi::sqlite3_auto_extension`.
   - Hashes canonical workspace paths to assign unique DB databases under AppData.
   - Manages relational tables (`files`, `symbols`) and the virtual vector table (`vec_symbols` using the `vec0` virtual table engine for 768-dimensional float arrays).
   - Implements `f32_slice_to_u8_slice` utilizing `zerocopy` for zero-copy binary bindings.
   - Exposes SIMD-accelerated local searches via `search_symbols_simd` and standard SQL query queries via MATCH.

5. **[simd.rs](file:///d:/Project/Antigravity/src/backend/src/simd.rs)**:
   - Implements dynamically routed vector similarity solvers.
   - Checks CPU features at runtime to choose:
     - **AVX-512** (FMA, T0 prefetching, 8-way unrolled loop, 128 float elements per iteration).
     - **AVX2 & FMA** (T0 prefetching, 8-way unrolled, 64 float elements per iteration).
     - **ARM NEON** (assembler `prfm` prefetching, 32 elements per iteration).
     - **Scalar** (standard loops fallback).

6. **[lsp.rs](file:///d:/Project/Antigravity/src/backend/src/lsp.rs)**:
   - Implements an asynchronous JSON-RPC Language Server Protocol client communicating with language servers (like rust-analyzer or typescript-language-server).
   - Automatically installs `typescript-language-server` locally using `npm` under `D:\Softwares\Installed\Antigravity\lsp-servers\ts-lsp` if missing from PATH.
   - Manages text sync, incremental text edits, hover info, definition queries, formatting requests, code actions, and rename events.
   - Features a self-healing watchdog monitor that automatically restarts crashed language servers and re-syncs all open document buffers.

7. **[embeddings.rs](file:///d:/Project/Antigravity/src/backend/src/embeddings.rs)**:
   - Builds custom `reqwest` clients with pool keepalives and dynamic SSL certificates gates.
   - Generates vector embeddings using Gemini's `text-embedding-004` (supporting chunked batching of 100 texts) or local OpenAI-compatible endpoints.
   - Safeguards against boundary crashes using Unicode-safe character truncation.

8. **[inference.rs](file:///d:/Project/Antigravity/src/backend/src/inference.rs)**:
   - Streams text completion tokens from Gemini (`gemini-1.5-pro` streamGenerateContent) or local OpenAI servers.
   - Extracts text from local documents and parses PDFs via `pdf_extract` to inject text context.
   - Parses SSE streams line-by-line, emitting telemetry updates (TTFT, TPS metrics) to the frontend.

9. **[logger.rs](file:///d:/Project/Antigravity/src/backend/src/logger.rs)**:
   - Structured logging based on `tracing-subscriber` layers.
   - `TelemetryBuffer`: Thread-safe fixed capacity LRU buffer exposing colored logs.
   - `RotatingFileWriter`: Writes plain-text daily rotated log files in AppData.
   - Dynamic reload filter handles runtime log level changes.
   - Dynamic regex-free credential redactor (`redact_secrets`) runs in $O(N)$ linear time to mask Gemini and OpenAI tokens.

10. **[security.rs](file:///d:/Project/Antigravity/src/backend/src/security.rs)**:
    - Encapsulates API keys in `ObfBox`, obfuscated at runtime with dynamic rolling XOR keys. Derives `Zeroize` and `ZeroizeOnDrop` traits to wipe keys from memory when dropped.
    - Connects to Windows Data Protection API (DPAPI) via FFI (`CryptProtectData`, `CryptUnprotectData`) utilizing entropy parameters to store secrets securely in the Windows Credential Manager keyring.

11. **[cache.rs](file:///d:/Project/Antigravity/src/backend/src/cache.rs)**:
    - Thread-safe capacity-limited LRU in-memory cache (`SymbolCache`) for Tree-sitter parsed AST symbols.

12. **[sandbox.rs](file:///d:/Project/Antigravity/src/backend/src/sandbox.rs)**:
    - FFI bindings wrapping Win32 Job Objects. Enforces job-wide memory commits (512MB), concurrency caps (32 concurrent processes), and below-normal priority classes.
